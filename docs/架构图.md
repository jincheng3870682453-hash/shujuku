## 2. 请求处理流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant FE as React 前端
    participant GW as Flask 网关
    participant Auth as 认证模块
    participant Perm as 权限检查
    participant Audit as 审核引擎
    participant BL as 业务逻辑
    participant DB as 数据库适配器
    participant DS as SQLite / MySQL

    U->>FE: 操作（新增/编辑/删除数据）
    FE->>GW: HTTP Request + Bearer Token
    GW->>Auth: before_request 恢复 Session
    Auth->>Perm: 检查用户权限
    alt 权限不足
        Perm-->>FE: 403 Forbidden
    else 权限通过
        Perm->>Audit: 检查是否需要审核
        alt 非boss + 审核开启
            Audit->>DB: 写入 pending_changes 表
            Audit-->>FE: 200 "已提交审核"
        else boss 或审核关闭
            Audit->>BL: 直接执行业务逻辑
            BL->>DB: SQL 操作
            DB->>DS: 执行
            DS-->>DB: 结果
            DB-->>BL: 结果
            BL-->>FE: 200 操作成功
        end
    end
```

## 5. 审核工作流

```mermaid
stateDiagram-v2
    [*] --> 用户操作: 新增/编辑/删除/字段变更

    用户操作 --> 权限检查
    权限检查 --> boss直接执行: boss 角色
    权限检查 --> 审核判断: 非 boss 角色

    审核判断 --> boss直接执行: global_audit = false
    审核判断 --> 写入待审核: global_audit = true

    写入待审核 --> 待审核队列: pending_changes 表

    待审核队列 --> 审核通过: 管理员 approve
    待审核队列 --> 审核驳回: 管理员 reject

    审核通过 --> 自动执行: 解析原始操作并执行
    审核驳回 --> 操作取消: 记录驳回原因

    自动执行 --> 记录日志: operations_log 表
    boss直接执行 --> 记录日志
    操作取消 --> 记录日志

    记录日志 --> [*]
```

## 6. AI 分析流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant FE as AIAnalysis.tsx
    participant GW as Flask 网关
    participant AI as AI 服务
    participant LLM as LLM 模型<br/>OpenAI / DeepSeek<br/>通义千问 / 文心一言 / 自定义
    participant DB as 数据库适配器

    U->>FE: 输入问题（文本 / 语音）
    FE->>FE: 按角色注入身份提示<br/>员工 → 仅本人数据范围
    FE->>GW: POST /api/ai/analyze<br/>+ Bearer Token + API Key(仅内存)
    GW->>AI: 校验权限 · 构造数据摘要
    AI->>DB: 读取统计/审计/用户数据（按角色裁剪）
    DB-->>AI: 数据摘要
    AI->>LLM: 发送提示词 + 数据摘要
    LLM-->>AI: 流式响应（打字机效果）
    AI-->>FE: 报告流式返回
    FE->>FE: 报告渲染 + 多轮追问（/api/ai/chat）
    FE->>GW: 历史记录防抖 800ms 自动保存
    GW->>DB: POST /api/ai/history<br/>ai_analysis_history 表（按用户隔离）
```

## 10. 性能优化要点

| 层级 | 优化措施 | 实现位置 |
| :--- | :--- | :--- |
| 后端 | SQL 分页查询（LIMIT/OFFSET，pageSize 上限 100） | `app.py` 数据/审核/日志/用户列表接口 |
| 前端 | React Query 缓存 `staleTime: 30s` + `placeholderData`，翻页无 loading 闪烁 | `DataTable.tsx` |
| 前端 | 搜索防抖 500ms，减少无效请求 | `DataTable.tsx` |
| 前端 | 字段编辑自动保存防抖 300ms | `Columns.tsx` |
| 前端 | AI 历史记录自动保存防抖 800ms | `AIAnalysis.tsx` |
| 前端 | 主题配色保存防抖 500ms 同步后端 | `FloatingThemeButton.tsx` |
| 后端 | 字段统计按取样计算（LIMIT 1000），避免全表扫描 | `app.py` 统计接口 |
| 前端 | 大量 `useMemo` / `useCallback` 避免无效重渲染 | 各页面组件 |
| 渲染 | ECharts 图表实例按需加载与复用 | `Charts.tsx` |
