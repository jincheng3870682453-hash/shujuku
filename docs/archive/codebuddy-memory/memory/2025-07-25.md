# 2025-07-25 工作日志

## 权限过滤 + 审核日志密码过滤修复

### 1. 数据权限过滤（_created_by 系统列）
- `init_db()`: 自动检测并添加 `_created_by VARCHAR(255)` 系统列到 `rows_data`
- `api_list_rows`: 非 boss 角色只返回 `_created_by = username` 的数据行
- `api_add_row`: 新增行时自动写入 `_created_by = session['username']`
- `api_import`: 导入行时也写入当前用户名
- 审批通过 `insert` 类型时：根据 `requested_by` 查询用户名写入 `_created_by`
- `api_update_row`: 非 boss 只能修改自己创建的行
- `api_delete_row`: 非 boss 只能删除自己创建的行
- `api_stats`: 非 boss 只统计自己创建的行的数据
- `api_export`: 非 boss 只导出自己创建的行
- boss 角色不受任何限制，可查看/操作所有数据

### 2. 审核日志密码过滤增强
- 将密码过滤从仅 `new_value` 扩展到同时检查 `new_value` 和 `old_value`
- 密码敏感键名扩展到: password, password_hash, new_password, old_password, confirm_password
- 不再仅限 add_user/update_user 类型，对所有包含密码键的审核记录统一脱敏

## Bug 修复轮次（同日后续）

### 修复 1：DataTable.tsx JSX 解析错误
- **现象**：Vite 报 `Expected corresponding JSX closing tag for <>` 在 line 642
- **根因**：之前替换 `<Card>` → `<div className="card-surface">` 时工具栏代码被重复插入，导致多余 `</div>` 和重复的 `<Space wrap>` 工具栏
- **修复**：删除 556-565 行重复的工具栏代码

### 修复 2：页面白屏
- **现象**：前端白屏无渲染
- **根因**：`main.tsx` 中 `import { antdTheme } from './styles/theme'` 命名导入，但 `theme.ts` 使用 `export default`
- **修复**：改为 `import antdTheme from './styles/theme'`

### 修复 3：useRole 角色判定失效
- **根因**：`Login.tsx` 登录成功只存了 `token` 到 localStorage，未存 `user`（username + role）。`useRole()` hook 依赖 `localStorage.getItem('user')` 来判定角色，导致 isAdmin/isBoss 始终为 false/undefined
- **修复 1**：`Login.tsx` 第 19 行新增 `localStorage.setItem('user', JSON.stringify({...}))` 
- **修复 2**：`AppLayout.tsx` 退出登录时新增 `localStorage.removeItem('user')` 清理

### 修复 4：审计日志菜单路由不匹配
- **现象**：点击"审计日志"报 404 Not Found
- **根因**：菜单 key `/audit-log` 但路由注册的是 `/logs`
- **修复**：菜单改为 `/logs`

## 背景质感切换系统全面重构（同日）

### 重构目标
消除 `!important` 硬切，改为 CSS 变量 + 特异性选择器平滑驱动，添加 `data-theme` 别名支持。

### 核心改动

**`frontend/src/styles/textures.css`（重写）**
- 8 种质感（Glass/Frosted/Metallic/Paper/Neon/Liquid Mesh/Depth/Flat）完整 CSS 变量体系
- 所有组件覆写使用 `html[data-texture]` 前缀（特异性 0,2,1），覆盖 Ant Design 5 的 `:where()`（0,1,0）
- 对于 index.css 中已用 `!important` 的属性（background 等），纹理层同步使用 `!important` 确保变量生效
- 新增 `--tx-glass-alpha` CSS 变量，替代 JS `<style>` 标签注入
- 新增 `data-theme` 属性映射（8 种 body-bg 别名）
- 200ms `cubic-bezier(0.4, 0, 0.2, 1)` 过渡 + 150ms fade 切换动画
- 背景效果：SVG 噪点纹理、纸质纤维、金属拉丝、霓虹网格+扫描线、液态流动动画

**`frontend/src/pages/Settings.tsx`（精简）**
- 删除 `applyGlobalGlassEffect()` 函数（JS 注入 `<style>` 标签的旧方案）
- 替换为 `applyGlassOpacity()` — 直接设置 `--tx-glass-alpha` CSS 变量
- `switchTexture()` 同步设置 `data-texture` + `data-theme` 双属性
- 精简 useEffect：移除玻璃样式注入清理逻辑

**`frontend/src/main.tsx`（增强）**
- `initTexture()`：同步设置 `data-texture` + `data-theme`
- 初始化 `--tx-glass-alpha` 从 localStorage 恢复

**`frontend/src/index.css`（修复冲突）**
- `.ant-card` 移除 `border: none !important; box-shadow: ... !important;`，改为非重要声明
- 新增 `html:not([data-texture])` 回退规则兜底
