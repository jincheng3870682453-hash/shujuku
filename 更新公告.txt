更新公告

版本：v6.0
发布日期：2026年8月14日

本次更新内容：

【性能优化】
- 后端分页查询：数据、审核、日志、用户列表全部改为 SQL 分页（pageSize 上限 100），大数据量响应更快
- React Query 缓存优化：翻页切换零 loading 闪烁
- 防抖机制：搜索 500ms、字段编辑 300ms、AI 历史 800ms、主题配色 500ms
- 渲染优化：useMemo / useCallback 减少无效重渲染，ECharts 图表实例复用
- 字段统计取样计算，避免全表扫描

【升级】
- AI 操作逻辑升级：
  · 多模型预设：OpenAI / DeepSeek / 通义千问 / 文心一言 / 自定义
  · 智能联网搜索：切换模型自动开关
  · 语音输入：直接说出分析问题
  · AI 历史记录：报告 + 对话按用户隔离保存在后端
  · 错误处理增强：服务商报错中文友好化
  · 数据摘要按角色裁剪，AI 只看权限范围内数据
- 自定义背景及质感系统：
  · 9 种背景质感：玻璃/磨砂/金属/纸张/霓虹/液态网格/深度/透明/极简平面
  · 四色自定义配色：品牌强调色、背景色、卡片背景色、文本颜色
  · 玻璃透明度调节、霓虹电光紫/电光青强调色
  · 自定义背景图上传
  · 全 CSS 变量驱动，150ms 平滑过渡，按用户隔离存储
